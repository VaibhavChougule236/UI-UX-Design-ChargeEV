# ⚡ ChargeEV - UI/UX Design for EV Charging Mobile App

This repository contains the **UI/UX design** of a modern Electric Vehicle (EV) Charging Mobile Application.

The goal of this project is to provide a **seamless, user-friendly, and efficient experience** for EV users to locate, book, and manage charging stations.

---

## 🚀 Features

- 🔍 Find nearby EV charging stations
- 📍 Interactive map-based UI
- ⚡ Real-time charging availability
- 📅 Slot booking system
- 👤 User profile management

---

## 🎨 Design Highlights

- Clean and modern UI
- Consistent color palette for energy theme ⚡
- Smooth navigation flow  

---

## 📂 Project Structure

- `Screen Views UI-UX/` → Contains all UI screen designs
